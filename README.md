# Star Network — Panna

Astro static website starter for Star Network, Panna.

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

The logo is already included at `public/logo.png`.

### Before launch
- Replace `https://example.com` in `astro.config.mjs` with the final domain.
- Confirm the final service coverage areas.
- Confirm GST/pricing presentation and any installation/router charges before publishing.
- Add real Google Maps embed and social links if supplied by the client.
